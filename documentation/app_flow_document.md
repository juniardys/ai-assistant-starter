# App Flow Document

## Onboarding and Sign-In/Sign-Up
When a new user opens the AI Assistant app for the first time, they see a splash screen branded with the app’s logo. The splash screen smoothly transitions into a welcome screen that offers two clear options: create a new account or sign in to an existing one. Users who choose to create a new account can do so by either entering their email address and choosing a password or by tapping the "Continue with Google" button. If they opt for email, they are guided through an input screen where they type their email, create a secure password, and confirm the password on the next screen. After tapping "Sign Up," the app sends a verification email and prompts them to check their inbox. Once their email is verified, they are automatically taken to the post-verification sign-in screen.

If users choose "Continue with Google," the app opens a standard Google account picker where they select the Google account they wish to use. Upon granting the necessary permissions, including access to Google Calendar and the Gemini API, they are redirected back into the app, already signed in. The sign-in state is saved, so on subsequent launches, users skip the welcome screen and land directly in the app.

On the sign-in screen, returning users can enter their email and password or tap the Google sign-in option if they previously registered that way. There is a "Forgot Password" link below the form that leads to a password recovery screen. There, the user enters their email and taps "Send Reset Link," prompting the app to send an email with instructions. After resetting their password, they return to the sign-in screen to enter their new credentials.

Signing out is always one tap away in the Settings section. When a user taps "Sign Out," the app clears all local authentication tokens and navigates back to the initial welcome screen, ready for another user to sign in or for the same user to authenticate again.

## Main Dashboard or Home Page
After signing in, users arrive at the Home Page, which uses a bottom tab bar to switch between the app’s core sections. The first tab is labeled "Chat," the second is "Tasks," the third is "Calendar," and the fourth is "Settings." The top of the screen features a friendly greeting and, on the Chat screen, a small profile icon that leads to user details. Each tab displays a consistent header and uses the app’s theme colors for clarity.

By default, users land on the Chat tab. The bottom tab bar remains visible as they move through the app, making it easy to jump between features. Swiping gestures and the file-based routing system handle screen transitions. For example, tapping the Tasks tab brings up a scrollable list of current tasks, and selecting the Calendar tab presents the month or week view of events. Tapping the Settings tab reveals account settings, themes, and sign-out options. The Home Page is designed to keep navigation intuitive and fluid, so users always know where they are and how to move to another part of the app.

## Detailed Feature Flows and Page Transitions
### AI Chat Interface
When users tap the Chat tab, the app navigates to the main chat screen. There they see a scrollable view of past messages organized as chat bubbles. At the bottom, a text input field invites them to type a question or instruction. As soon as they start typing, the send button becomes active. Upon tapping send, the message appears in the list immediately while a typing indicator shows that the AI is composing its response. The app uses a custom hook to send the user’s message to the Gemini API, receive responses in a streamed manner, and render the AI’s answer bubble by bubble. If users want to revisit a previous conversation, they can pull down to refresh the history or tap a calendar icon in the header to filter messages by date.

### Task and Notes Management
Tapping the Tasks tab takes users to a screen that lists tasks and notes stored in the cloud. At the top, there is an "Add" button that opens a modal overlay. In the modal, users type a task title, choose a due date from a date picker, and select a priority flag or tag. They tap "Save" to write the new task to Firestore. The list updates in real time and shows newly added items instantly. To edit a task, users tap on its list item, which opens an edit screen identical to the creation modal but prefilled with existing details. Deleting a task involves tapping a delete icon and confirming the action in a dialog. All changes are synchronized across devices automatically.

### Calendar Integration
When users select the Calendar tab, the app requests permission to access their Google Calendar if not already granted. Once permission is in place, the screen displays a month grid with dots indicating days that have events. Tapping a day opens a list of events for that date. To create a new event, users tap a floating action button and fill in the event title, start and end times, location, and description. Tapping "Save" sends the event details to the Google Calendar API and writes an entry to Firestore. If events are added on the Google web interface or another device, they appear in the app within seconds thanks to real-time updates. Users can tap an existing event to view its details or edit it. After editing, tapping "Update" writes the changes back to both Google Calendar and the app’s local store.

### Navigation Between Pages
The app’s file-based routing system automatically maps each screen file to its route. When users navigate via the bottom tabs, the router loads the corresponding file. Within each module—Chat, Tasks, and Calendar—deep links are supported. For instance, tapping an event on a calendar widget opens the detail page at the path `/calendar/[eventId]` so users can share or bookmark specific screens. Swiping down from the header in any module refreshes the data. Navigating back uses the standard device back button on Android or a back arrow in the header on iOS.

## Settings and Account Management
The Settings tab presents user information at the top, including name, email, and profile photo. Below that, users find toggles to switch between light mode and dark mode, along with a section to manage notification preferences. For notifications, users grant push notification permission and then choose which reminders they want to receive: daily summary, upcoming event alerts, or task due notifications. There is also an option to connect or disconnect a Google account, which allows users to reauthorize or revoke calendar and Gemini access. A final button labeled "Sign Out" ends the session and returns users to the welcome screen. After making any change, tapping the back arrow or bottom tab automatically brings the user back to the Home Page.

## Error States and Alternate Paths
If a user enters an incorrect password or an unrecognized email during sign-in, the app displays a clear error message in red text below the input fields, prompting users to retry or use the password recovery flow. During Google sign-in, if the user denies a permission request, the app shows a dialog explaining why the app needs calendar or AI access and offers a button to retry. When creating or editing tasks and events, if the network connection is lost, a non-blocking banner appears at the top stating "Offline mode: changes will sync when you reconnect." The app continues to allow data entry locally, and once the connection returns, it automatically pushes the updates. Any API call that fails due to unexpected errors results in a toast notification or alert dialog that explains the problem in simple terms and suggests a retry or contacting support.

## Conclusion and Overall App Journey
From the moment users launch the AI Assistant app, they experience a smooth onboarding that can use either email or Google sign-in with the proper permissions requested upfront. After authentication, the bottom tab navigation lets them move seamlessly between the chat interface, task list, calendar views, and settings. Each feature is connected through real-time synchronization and intuitive screen transitions powered by file-based routing. Users can manage tasks and notes, schedule meetings on their Google Calendar, and interact with the AI assistant through a responsive chat interface. Settings allow personalization of appearance and notifications, while thoughtful error handling ensures that users can continue working even when offline or when permissions need to be revisited. Overall, the app flow guides users from sign-up to everyday productivity, helping them stay organized and get intelligent assistance at every step.
